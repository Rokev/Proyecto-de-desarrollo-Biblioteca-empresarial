# Biblioteca Red — Frontend Angular 22 (v1.1)

Aplicación SPA en Angular 22 (Standalone, Zoneless, Signals, `OnPush`) bajo arquitectura Atomic Design, actualizada con todas las mejoras y casos del Plan de Pruebas.

## Instalación y Ejecución
```bash
npm.cmd install --legacy-peer-deps
npm.cmd start
```
